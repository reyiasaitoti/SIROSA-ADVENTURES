# SIROSA Adventures

A responsive static Kenya safari and tour website built with HTML, CSS and JavaScript.

Destination guides live in `places/` for the Maasai Mara, Amboseli, Samburu and Diani Coast. Each guide includes practical planning notes, an external destination source, and a link back to the trip inquiry form with the destination prefilled.

## Run locally

Open `index.html` in a browser. The site has no build step or framework dependency.

## Before launch

- Confirm the public contact email in `index.html` and configure the inquiry form recipient in `src/main.js`.
- Replace the sample itineraries, inclusions and indicative price copy with SIROSA's confirmed trip details and rates.
- Add the company's verified phone/WhatsApp, social accounts, legal details, booking terms and cancellation policy once available.
- Replace or approve the current Unsplash photography for commercial use and add SIROSA's own imagery where possible.
- Connect the inquiry form to a CRM or booking endpoint if inquiries should be stored rather than sent through the visitor's email app.
- Add verified client reviews, guide profiles, certifications and conservation partners only after SIROSA confirms them.

The current inquiry address is an editable placeholder and must be confirmed before publishing. The form composes a message in the visitor's email app; it does not transmit or store personal data on a server.
